This folder contains the source and website variants of Victor's Kotoros sign.

## Source asset

Expected source file:
- `kotoros-original.png` — original black hand-drawn source, preserved as archive/reference

## Website variant

Expected website file:
- `kotoros-pink.png` — pink website treatment derived from the original source

## Usage rules

Kotoros is Victor's personal sign. It is not a conventional logo.

- visible website use: pink only
- rare use
- maximum one important occurrence per viewport
- never monumental
- never repeated as a pattern
- never use black or red as the dominant public identity treatment
- cropping, partial hiding, transparency or progressive drawing are allowed
- desired reaction: “What is that?” rather than “That’s his logo.”

See `../../../DESIGN_SYSTEM.md` and `../../../AGENTS.md` for the full identity and interaction rules.
