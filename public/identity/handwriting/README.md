# Handwriting assets

Real scanned handwriting only — per `DESIGN_SYSTEM.md`: "Never use a fake handwriting font. Use sparingly."

Drop one or more scanned handwriting images here (e.g. `ep-001-paris-2026.png`). The site picks up the first one automatically and displays it rarely, as a human trace after the visitor's first interaction (Archive → Human Trace → Studio) — no code change needed.

Until a real scan is added, this folder stays empty and no handwriting appears on the site.
